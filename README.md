# 2sizdev UI fixes — Vocabulary set cards + letter-keyboard selection

This build keeps the previously approved behavior and only changes the requested vocabulary UI/keyboard behavior.

## Vocabulary sets
- Colorful, compact set cards with accent and hover effect.
- Added **Xem bộ từ →** primary action.
- Keeps **Sửa** and **Xóa**.
- Uses **Độ thành thạo** instead of Mastery.

## Letter-order vocabulary practice
- No direct text input.
- No numeric key labels.
- Press the actual letter key to select the matching visible tile.
- Duplicate letters are consumed one tile at a time (e.g. pressing `p` twice selects both `p` tiles).
- Backspace removes the last selected letter.
- Mouse/touch selection remains available.
